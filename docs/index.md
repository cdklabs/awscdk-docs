## What is the AWS CDK

The AWS Cloud Development Kit (CDK) is a framework for defining cloud infrastructure as code and provisioning it through AWS CloudFormation. Instead of writing YAML or JSON templates by hand, you write ordinary code, in TypeScript, Python, Java, C#, or Go, and the CDK synthesizes it into a CloudFormation template behind the scenes. This site documents every construct, class, interface, and enum available for that code: what it does, what it takes, and how it fits together, with a working example on every page.

## Getting started

New to the CDK? The [Getting Started guide](https://docs.aws.amazon.com/cdk/v2/guide/getting-started.html) walks you through installing the CDK CLI, creating your first app in any of the five supported languages (TypeScript, Python, Java, C#, or Go), and deploying it. The [CDK Workshop](https://cdkworkshop.com) is a longer, hands on tutorial if you want to build something real before diving into the reference.

Once your project is set up, use this site as your reference: every construct, class, interface, and enum has a working example on its page, shown in whichever language you pick with the navbar's language switcher.

Already comfortable with the CDK? Jump straight to the [API Reference](/v2/) or use the search bar to find the construct you need.
